# QAZTECH® Tutor 8B (v0.2 preview)

Multilingual engineering tutor for Microsoft Azure topics. It explains concepts, corrects misconceptions and writes certification-style practice questions with explanations, in English, Russian, Kazakh, Arabic and Spanish.

## Quick start
Ollama: `ollama run qaztech-platform/tutor`

Transformers:
```python
from transformers import AutoModelForCausalLM, AutoTokenizer
m = "qaztech-platform/QAZTECH-Tutor-8B"
tok = AutoTokenizer.from_pretrained(m)
model = AutoModelForCausalLM.from_pretrained(m, torch_dtype="auto", device_map="auto")
msgs = [{"role": "system", "content": "You are an expert engineering tutor. Reply in the student's language."},
        {"role": "user", "content": "Give me a practice question on Azure RBAC"}]
ids = tok.apply_chat_template(msgs, add_generation_prompt=True, enable_thinking=False, return_tensors="pt").to(model.device)
print(tok.decode(model.generate(ids, max_new_tokens=400)[0][ids.shape[1]:], skip_special_tokens=True))
```
Use `enable_thinking=False`: the model was trained without reasoning traces.

## Training
- Base: Qwen/Qwen3-8B (Apache-2.0). LoRA (r=16, alpha=32, all linear layers), 3 epochs, lr 1e-4, bf16, merged into the base weights.
- Data: 5,107 synthetic tutoring dialogues (4,907 train / 200 held out), generated by Qwen3-30B-A3B-Instruct-2507 from Microsoft Azure documentation on role-based access control, virtual networks, Azure Resource Manager and App Service.
- Modes: explanation 1,804; misconception correction 1,613; certification-style practice questions 1,690.
- Languages: ru 1,149; kk 1,023; es 1,011; en 980; ar 944.
- Filters: question and answer in the same language, no references to unseen source text, no mixed scripts, deduplication.
- Held-out eval loss 0.795, token accuracy 0.773.

## Limitations
- Facts can be wrong: incorrect permission names and behaviours were observed in testing. Use with retrieval over official documentation (RAG) and verify against Microsoft Learn.
- Kazakh and Arabic output has not yet been reviewed by native speakers; Kazakh phrasing can be awkward.
- Coverage is limited to the four Azure documentation areas above.
- Contains no real Microsoft exam questions. Not affiliated with or endorsed by Microsoft.
